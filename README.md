# Tradon Frontend

Modern e-commerce frontend built with React, Tailwind CSS, and Vite.

## Features

- ✨ Modern UI/UX with Tailwind CSS
- 🚀 Fast development with Vite
- 📱 Fully responsive design
- 🛒 Shopping cart functionality
- 🔍 Product search and filtering
- ⭐ Product ratings and reviews
- 💳 Checkout experience
- 🎨 Beautiful product cards

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/        # Reusable components
│   ├── Navbar.jsx

│   └── Features.jsx
├── pages/            # Page components
│   ├── Home.jsx
│   ├── Products.jsx

│   └── Cart.jsx
```

## Pages

- **Home** - Landing page with hero banner, featured products, and flash sales
- **Products** - Product listing with filters and sorting
- **Product Detail** - Detailed product information with reviews
- **Cart** - Shopping cart with order summary
